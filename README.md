# DevFlow AI

**Intelligent Developer Workspace for AI-Assisted Project Management**

> IT Track — AI Agent · Capstone Project · Prototype v1.0

---

## Overview

DevFlow AI is a web application prototype designed to help software developers organize development tasks, break down project requirements, track bugs, monitor project progress, and receive AI-assisted workflow recommendations — all through a centralized dashboard.

This project demonstrates how AI Agent concepts can be applied to a software development workflow. The prototype is built entirely with HTML5, CSS3, and vanilla JavaScript, with no external dependencies or backend.

---

## Features

| Feature | Description |
|---|---|
| **Dashboard** | Real-time overview of total tasks, completed tasks, in-progress tasks, open bugs, and project progress percentage |
| **Task Management** | Add tasks, update status (To Do / In Progress / Done), change priority (High / Medium / Low), and filter by status or priority |
| **Bug Tracking** | View, search, and filter bug reports by status, severity, and priority; report new bugs via QA form; update bug status inline |
| **AI Assistant** | Simulated chat interface for task planning, prioritization advice, and workflow recommendations |
| **Requirement Breakdown** | Simulated AI decomposition of project requirements into structured development task lists |
| **Project Progress** | Live progress bar calculated from task completion rate |
| **Theme System** | Dark and light theme with localStorage persistence; no flash of wrong theme on load |

## Usage

### Navigation
Use the **sidebar** (desktop) or the **☰ hamburger menu** (mobile) to switch between sections:
- **Dashboard** — project overview and recent tasks
- **Tasks** — full task list with filters and add-task form
- **Bug Tracking** — bug list with search, filters, and report form
- **AI Assistant** — chat and requirement breakdown tabs

### Adding a Task
1. Go to **Tasks**.
2. Click **+ Add Task**.
3. Enter a title (required), optional description, status, and priority.
4. Click **Add Task**.

### Reporting a Bug
1. Go to **Bug Tracking**.
2. Click **+ Report Bug**.
3. Fill in the title, description, related feature, and severity (required fields).
4. Optionally add steps to reproduce, expected result, and actual result.
5. Click **Submit Report** — the bug is saved to `localStorage` and persists across sessions.

### Updating Status
- **Tasks:** Use the inline status and priority dropdowns on each task item.
- **Bugs:** Use the inline status dropdown on each bug item, or click a bug to open the detail view and use the **Update Status** control there.

### AI Assistant
- **Chat tab:** Type any question about task planning, priorities, bug management, or sprint planning and press **Send**.
- **Requirement Breakdown tab:** Paste a project requirement and click **Generate Tasks** to receive a structured list of suggested development tasks.

> ⚠ AI responses are **simulated** using predefined rules and keyword patterns. They are not generated by a real AI model.

### Theme
Click the **☾ / ☀ toggle** in the sidebar (or the compact icon in the mobile topbar) to switch between dark and light mode. The preference is saved automatically.

## Data Model

### Task
```
id          number      Auto-incremented identifier
title       string      Short task title (required)
description string      Optional detail
status      string      'todo' | 'inprogress' | 'done'
priority    string      'high' | 'medium' | 'low'
```

### Bug
```
id          number      Auto-incremented identifier
bugId       string      Human-readable ID, e.g. "BUG-007"
title       string      Short bug title (required)
description string      Description of the issue (required)
feature     string      Related feature or page (required)
steps       string      Steps to reproduce (optional)
expected    string      Expected result (optional)
actual      string      Actual result (optional)
severity    string      'critical' | 'high' | 'medium' | 'low' (required)
priority    string      'high' | 'medium' | 'low'
status      string      'open' | 'in-progress' | 'resolved'
source      string      'sample' (demo data) | 'reported' (user-submitted)
taskId      number|null Linked task ID (null if not linked)
createdAt   string      ISO 8601 timestamp
```

**Seed data:** 8 sample tasks and 6 sample bugs are preloaded for demonstration. Only user-reported bugs are persisted via `localStorage`.

## Known Limitations

- **AI is simulated** — responses are generated by regex pattern rules, not a real AI model.
- **Task data is not persisted** — tasks reset on page reload (only user-reported bugs are saved).
- **Task deletion** is not implemented (outside PRD scope).
- **Bug editing** is limited to status changes only after initial report.
- **No authentication** — single-user, local prototype only.
